# Neovim 練習帳

[editing.md](editing.md) の内容を手で動かして覚えるための課題集。解答キーはすべてこの設定で動作を確かめてある。

## 使い方

1. このファイルのコピーを Neovim で開く (`cp practice.md /tmp/practice.md` など。壊しても困らないように)
2. 各課題の **対象** ブロックにカーソルを置く
3. **目標** の形になるように、自力で編集する
4. 詰まったら **解答キー** を見る (`<Esc>` `<CR>` などはそのキーを押す)

失敗したら `u` で戻せる。

この設定ならではの注意:

- `x` は**レジスタを汚さない削除オペレータ**。1 文字消すなら `xl`、行は `xx`、単語は `xiw`
- マクロは `qq` で記録 → `q` で停止 → **`Q` で再生** (`@q` 相当)
- `/` は **very magic** (`\v`)。`(` `+` `|` はメタ文字として働く
- 数値の増減は `<C-a>` / `<C-x>` (数値以外も切り替える)

## 1. テキストオブジェクト

### 1-1. 単語を書き換える

**目標**: `oldName` を `newName` に。

**対象**:

```text
const result = oldName + 1
```

**解答キー**: `oldName` の上で `ciwnewName<Esc>`

### 1-2. クォートの中身だけ変える

**目標**: `"foo"` を `"bar"` に。クォートは残す。

**対象**:

```text
const label = "foo"
```

**解答キー**: 行頭からでも `ci"bar<Esc>` (`ci"` はクォートより手前にいても効く)

### 1-3. 関数の本体を書き換える (Treesitter)

**目標**: `greet` の本体を `return 1` の 1 行にする。

**対象**:

```javascript
function greet() {
  console.log("hi");
  console.log("bye");
}
```

**解答キー**: 本体の中で `cifreturn 1<Esc>`

`dif` で消すだけにすると、インデントだけの行が 1 行残る。

### 1-4. 引数を 1 つ消す

**目標**: `foo(alpha, beta)` → `foo(alpha)`。カンマも一緒に消す。

**対象**:

```lua
foo(alpha, beta)
```

**解答キー**: `beta` の上で `daa` (`dia` だとカンマが残る)

### 1-5. インデントブロックをまとめて動かす

**目標**: `f` の本体 2 行を 1 段深くする。

**対象**:

```python
def f():
    a = 1
    b = 2

x = 3
```

**解答キー**: 本体の中で `>ii` (`ii` はインデントブロック。`ai` なら `def` 行まで含む)

このファイル (Markdown) の中では `ii` が `def` 行まで選んでしまうので、Python のバッファで試す。
対象の 5 行を `V4jy` でヤンク → `:new | setf python` → `P` で貼ってから解く。

### 1-6. 選択を構文単位で広げる

**目標**: `bar` から始めて、選択を `foo(bar, baz)` 全体まで広げてヤンクする。

**対象**:

```lua
local x = foo(bar, baz)
```

**解答キー**: `bar` の上で `v` → `an` (`bar`) → `an` (`(bar, baz)`) → `an` (`foo(bar, baz)`) → `y`

広げすぎたら `in` で 1 段戻る。

## 2. Surround

### 2-1. 単語をクォートで囲む

**目標**: `hello` → `"hello"`

**対象**:

```text
hello
```

**解答キー**: `ysiw"`

### 2-2. クォートの種類を変える

**目標**: `"hello"` → `'hello'`

**対象**:

```text
"hello"
```

**解答キー**: `cs"'`

### 2-3. タグを外す

**目標**: `<div>hello</div>` → `hello`

**対象**:

```html
<div>hello</div>
```

**解答キー**: `dst`

### 2-4. 関数呼び出しで囲む / 外す

**目標**: `value` → `print(value)` → `value` と往復する。

**対象**:

```lua
value
```

**解答キー**: `ysiwf` → 関数名を聞かれるので `print<CR>`。外すのはカッコの中で `dsf`

## 3. ドットリピート

### 3-1. 行末にセミコロンを足す

**目標**: 3 行すべての行末に `;`。

**対象**:

```text
const a = 1
const b = 2
const c = 3
```

**解答キー**: 1 行目で `A;<Esc>`、続けて `j.` を 2 回

### 3-2. cgn で同じ単語を順に書き換える

**目標**: すべての `get` を `fetch` に。

**対象**:

```text
getUser()
getOrder()
getProfile()
```

**解答キー**: `/get<CR>` → `cgnfetch<Esc>` → `.` → `.`

### 3-3. 箇条書きをチェックボックスにする

**目標**: 各行の `-` を `- [ ]` に。

**対象**:

```text
- task1
- task2
- task3
```

**解答キー**: 1 行目で `^a [ ]<Esc>`、続けて `+.` を 2 回

`j.` だと失敗する。`.` は「カーソルの後ろに入れる」を繰り返すだけなので、`j` で同じ列に降りると `- tas [ ]k2` のようになる。
`+` は次の行の先頭の非空白文字へ移るので、位置が揃う。

## 4. マクロ (基本)

### 4-1. リストを配列の要素にする

**目標**: 各行を `"value",` の形に。行頭と行末の 2 か所を直すので `.` 1 回では届かない。

**対象**:

```text
apple
banana
cherry
```

**解答キー**:

```vim
qq             " 記録開始
I"<Esc>        " 行頭に "
A",<Esc>       " 行末に ",
j              " 次の行へ
q              " 停止
2Q             " 残りの 2 行へ
```

### 4-2. 検索を混ぜて飛び飛びの行を処理する

**目標**: `log` で始まる行だけ `// ` でコメントアウト。`ok()` の行は触らない。

**対象**:

```text
log(a)
ok()
log(b)
ok()
log(c)
```

**解答キー**: 1 行目の行頭から

```vim
qq             " 記録開始
/^log<CR>      " 次の log 行へ
I// <Esc>      " 行頭にコメント
q              " 停止
99Q            " 当たらなくなるまで
```

`/log` にすると止まらない。検索はファイル末尾で先頭に戻るうえ、処理済みの `// log(b)` にも当たり続けて `// // // …` と増えていく。
`^log` なら処理済みの行には当たらず、全部終わると検索が失敗してマクロが止まる。

### 4-3. 行を複製して連番を振る

**目標**: 1 行を 5 行に増やし、番号を 1 〜 5 にする。

**対象**:

```text
test_case_0
```

**解答キー**:

```vim
yy4p           " 5 行にする
ggVG           " 全部選ぶ
g<C-a>         " 0,0,0,0,0 → 1,2,3,4,5
```

`<C-a>` は選択内を全部 +1、`g<C-a>` は行ごとに +1, +2, +3 … と階段状に増やす。
マクロでやるなら `test_case_1` から始めて `qqyyp<C-a>q` → `3Q` だが、`g<C-a>` の方が速い。

### 4-4. 数値以外を増減・切り替える

**目標**: 各行の値を `<C-a>` で変える。

**対象**:

```text
enabled = false
version = "v1.2.9"
release = 2024-01-31
mode    = a && b
```

**解答キー**: 対象の上にカーソルを置いて `<C-a>`

- `false` → `true`
- `v1.2.9` の `9` の上 → `v1.2.10`
- `2024-01-31` の `31` の上 → `2024-02-01` (年・月の上なら年・月が変わる)
- `&&` の上 → `||`

## 5. マクロ (上級)

### 5-1. 再帰マクロ (回数を数えない)

**目標**: 行数を数えずに、4-1 と同じ変換を最後まで走らせる。

**対象**:

```text
red
green
blue
yellow
```

**解答キー**: 1 行目で

```vim
qqq              " q レジスタを空にする
qq               " 記録開始
I"<Esc>A",<Esc>  " 1 行分の処理
j                " 次の行へ
@q               " 自分を呼ぶ (今は空なので何も起きない)
q                " 停止
Q                " 1 回で最後まで
```

### 5-2. 一致する行だけに適用する (`:g`)

**目標**: `TODO` を含む行だけ、末尾に ` <-- check` を付ける。

**対象**:

```text
clean this up TODO
this line is fine
fix later TODO
done
```

**解答キー**: マクロを使わずに直接書ける

```vim
:g/TODO/normal A <-- check
```

マクロで同じことをするなら、1 行目で記録して、**記録で変わった分を `u` で戻してから**流す。戻さないと 1 行目だけ二重に付く。

```vim
qqA <-- check<Esc>q   " 記録 (1 行目に付く)
u                     " 戻す
:g/TODO/normal @q     " TODO の行すべてに
```

### 5-3. 選んだ行に適用する (`:normal`)

**目標**: 選んだ 3 行を `// ` でコメントアウト。

**対象**:

```text
line one
line two
line three
```

**解答キー**: `Vjj` で 3 行を選び、`:` を押すと `:'<,'>` が入るので続けて `normal I// <CR>`

コメントアウトだけなら `gc` でもできる。`:normal` は「各行で同じ Normal 操作」を何にでも使える。

## 6. 矩形ビジュアル

### 6-1. 縦に並んだ行の先頭に入れる

**目標**: 3 行の先頭に `// `。

**対象**:

```text
line one
line two
line three
```

**解答キー**: 1 行目の行頭で `<C-v>2j` → `I// <Esc>` (`<Esc>` を押した時点で全行に入る)

### 6-2. 長さの違う行の末尾に足す

**目標**: 3 行の末尾に `,`。

**対象**:

```text
a = 1
bb = 2
ccc = 3
```

**解答キー**: `<C-v>2j` → `$` → `A,<Esc>`

`$` を押さずに `A` すると、選択の右端の列に揃って入る。

## 7. 置換

### 7-1. キャプチャで入れ替える

**目標**: `foo_bar` → `bar_foo`。

**対象**:

```text
foo_bar
```

**解答キー**: `:s/\v(\w+)_(\w+)/\2_\1/<CR>`

`:s` には `/` キーの very magic が効かないので、`\v` を自分で付ける。

### 7-2. 直前の検索を使い回す

**目標**: 行内の `aaa` をすべて `ccc` に。

**対象**:

```text
aaa bbb aaa
```

**解答キー**: `aaa` の上で `*` → `:s//ccc/g<CR>` (pattern を空にすると直前の検索が使われる)

### 7-3. quickfix で一括置換する

**目標**: このファイル (のコピー) にある `oldName` をすべて `newName` に。実際の作業では複数のファイルに対して同じことをする。

**解答キー**:

```vim
:vimgrep /[o]ldName/ %        " このファイルの一致を quickfix に入れる
:cdo s/[o]ldName/newName/ge   " 一致した行ごとに置換
```

`[o]ldName` と書いているのは、この解答キーの行そのものに当たらないようにするため (`oldName` と同じ文字列に一致するが、`[o]ldName` という文字列には一致しない)。
1-1 の対象やこの課題の目標の文も置き換わる。

実際の作業では `<leader>/` で grep して `<C-q>` で quickfix に送り、`:cdo s/old/new/ge | update` で保存まで済ませる。

## 8. 仕上げ

### 8-1. 検索で飛ぶ → 直す → 戻る

**目標**: `targetFn` の呼び出しまで飛び、引数の `1` を `2` にして、元の位置へ戻る。

**対象**:

```text
start here
// ... 省略 ...
targetFn(1)
```

**解答キー**: `start` の行で `/targetFn<CR>` → `f1` → `<C-a>` → `<C-o>` で戻る

### 8-2. 前のヤンクを貼り直す

**目標**: `first` と `second` を順にヤンクした後で、`first` を貼る。

**対象**:

```text
first second
```

**解答キー**: `first` の上で `yiw` → `w` → `yiw` → `o<Esc>` で下に空行を作って `p` (`second` が入る) → すぐに `<C-p>` (`first` に差し替わる)

もっと前のヤンクを探すなら `<leader>y` で履歴から選ぶ。
