# 編集テクニック

Vim の編集操作を、この設定で実際に使う形でまとめたもの。
キーの一覧は [keymaps.md](keymaps.md)、手を動かして覚えるなら [practice.md](practice.md)。

## 道具の選び方

同じような変更を何か所かに入れるときは、安い手から順に試す。

| 状況                                 | 手段                                                  |
| ------------------------------------ | ----------------------------------------------------- |
| 1 か所だけ                           | オペレータ + テキストオブジェクト (`ciw` `ci"` `daf`) |
| 同じ 1 操作を何か所かに              | 1 回やって、移動して `.`                              |
| 続いた行に同じ 1 操作                | 1 回やって、残りの行を `V` で選んで `:normal .`       |
| 検索で当たる箇所を、目で見ながら順に | `*` か `/` → `cgn` → `.` (飛ばすなら `n`)             |
| 規則的で件数が多い                   | `:%s/old/new/g`                                       |
| 条件に合う行だけに                   | `:g/pat/normal ...`                                   |
| 縦に揃った箇所                       | 矩形ビジュアル `<C-v>`                                |
| 複数ステップ + 位置取り              | マクロ (`qq` … `q` → `Q`)                             |
| 複数のファイル                       | grep → `<C-q>` → `:cdo`                               |

「`.` で届くか」を先に考えると、マクロの記録コストを払わずに済むことが多い。

## 移動

`hjkl` は微調整用。主役は検索・単語・構造単位のジャンプ。

| 範囲     | キー                                                                                                        |
| -------- | ----------------------------------------------------------------------------------------------------------- |
| 行内     | `f{c}` `t{c}` (`;` `,` で繰り返し)、`w` `b` `e`、`0` `^` `$`                                                |
| 画面内   | `{` `}` (段落)、`{n}j` `{n}k` (相対行番号を見て)、`H` `L` (画面の上端 / 下端)                               |
| ファイル | `/` `?` `*` `#` → `n` `N`、`gg` `G` `{n}G`                                                                  |
| 構造     | `]f` `]c` `]a` (関数・クラス・引数。`;` `,` で繰り返し)、`]i` `[i` (インデントブロック)、`M` (対応する括弧) |
| コード   | `gd` (定義)、`gr` (参照)                                                                                    |
| 画面位置 | `zz` `zt` `zb`、`<C-d>` `<C-u>` (この設定では移動後に画面中央に保つ)、`<C-f>` `<C-b>` (1 ページ)            |
| 見出し   | `]]` `[[` (Markdown とヘルプ)、`gO` (見出しの一覧)                                                          |

戻るための操作:

| キー                    | 動作                                                |
| ----------------------- | --------------------------------------------------- |
| `<C-o>` / `<C-i>`       | ジャンプ履歴を戻る / 進む (`gd` や検索のあとに戻る) |
| `g;` / `g,`             | 変更した場所を古い方 / 新しい方へ辿る               |
| `gi`                    | 最後に文字を入力した位置で Insert を再開            |
| `` `. ``                | 最後に変更した位置                                  |
| `m{a-z}` → `` `{a-z} `` | マークを置いて、そこへ戻る (`'{a-z}` なら行頭へ)    |
| `m{A-Z}` → `` `{A-Z} `` | 大文字のマークは、別のファイルからでも戻れる        |
| ` `` `                  | 直前のジャンプの前の位置                            |

マーク `z` は使わない。この設定の `J` がカーソル位置を保つために `mz` を使うので、上書きされる。

## 検索

| キー                | 動作                                                         | 例                               |
| ------------------- | ------------------------------------------------------------ | -------------------------------- |
| `/`                 | very magic の前方検索。`( ) + ? \| { }` がそのまま使える     | `/TODO\|FIXME`、`/(get\|set)\w+` |
| `?`                 | 記号をそのまま探す後方検索 (very nomagic)                    | `?items[0]`、`?user?.name`       |
| `*` / `#`           | カーソル下の単語で前方 / 後方検索                            |                                  |
| Visual で `*` / `#` | 選んだ文字列をそのまま前方 / 後方検索 (記号もエスケープ不要) | `foo.bar(` を選んで `*`          |
| `n` / `N`           | 次 / 前の一致 (画面中央に保つ)                               |                                  |
| `<Esc>`             | ハイライトを消す                                             |                                  |

- 小文字だけで打てば大文字小文字を区別しない。大文字を混ぜると区別する (`ignorecase` + `smartcase`)
- 検索は「探す」より「飛ぶ」ために使う。2〜4 文字で候補が絞れれば十分で、一意でなくても `n` で進めばよい
- 近くなら `f{c}` の方が速い。飛んだ後は `<C-o>` で戻れる
- very magic では `<` `>` が単語の境界になる (`/<get>` は `getter` に当たらない)

## オペレータ

`{オペレータ}{移動}` か `{オペレータ}{テキストオブジェクト}` の形で使う。組み合わせは掛け算なので、オペレータを 1 つ覚えると、知っている移動の数だけ使い道が増える。

| オペレータ         | 動作                              | 例                                                                 |
| ------------------ | --------------------------------- | ------------------------------------------------------------------ |
| `c` / `d` / `y`    | 変更 / 削除 / ヤンク              | `ct,` (`,` の手前まで書き換え)、`d}` (段落の終わりまで)、`yiw`     |
| `x`                | レジスタを汚さずに削除 (この設定) | `xiw`、`xt)`                                                       |
| `gU` / `gu` / `g~` | 大文字 / 小文字 / 反転            | `gUiw` (単語を大文字に)                                            |
| `>` / `<`          | インデントを増やす / 減らす       | `>ip`、`>ii`                                                       |
| `=`                | インデントを整える                | `=ip`、`=af`、`gg=G` (ファイル全体)                                |
| `gc`               | コメント                          | `gcip`、`gcaf`                                                     |
| `!`                | 外部コマンドに通して置き換える    | `!ip` → `sort` ([並べ替えと外部コマンド](#並べ替えと外部コマンド)) |

- 同じキーを 2 回押すと今の行が対象になる (`dd` `cc` `yy` `gUU` `==` `>>`)
- 回数は前に付ける。`3dd` で 3 行、`d3w` で 3 単語
- 検索も移動として使える。`d/foo<CR>` は `foo` の手前まで消す。
  ただしオペレータの後の `/` は very magic にならない (キーマップは Normal と Visual にだけ付けている)

## テキストオブジェクト

`{オペレータ}{i か a}{対象}` の形で使う。`i` は中身だけ、`a` は外側も含む。
オペレータのほか、`v` (選択) の後にも使える。

| 対象       | キー                                           | 例                                                   |
| ---------- | ---------------------------------------------- | ---------------------------------------------------- |
| 単語       | `iw` / `aw`、`iW` (`i<Space>` でも可)          | `ciw` で単語を書き換え                               |
| クォート   | `i"` / `a"` (`'` `` ` `` も同様)               | `ci"` はクォートより手前にいても効く                 |
| 括弧       | `i(` `i{` `i[` `i<` (`ib` = `i(`、`iB` = `i{`) | `ci(` で引数をまとめて書き換え                       |
| タグ       | `it` / `at`                                    | `cit` でタグの中身を書き換え                         |
| 段落       | `ip` / `ap`                                    | `yap`、`gcip`                                        |
| 関数       | `if` / `af`                                    | `daf` で関数ごと削除、`cif` で本体を書き換え         |
| クラス     | `ic` / `ac`                                    | `yac` でクラスごとヤンク                             |
| 引数       | `ia` / `aa`                                    | `cia` で引数を 1 つ書き換え、`daa` でカンマごと削除  |
| インデント | `ii` / `ai`                                    | `>ii` でブロックごとインデント (Python・YAML で便利) |
| ブロック   | `i%` / `a%`                                    | `if` … `end` の中身                                  |
| hunk       | `ih`                                           | `vih` で変更箇所を選ぶ                               |
| 構文ノード | Visual で `an` / `in`                          | `v` → `an` `an` … で 1 段ずつ外側へ広げる            |

- この設定の `a"` は後ろの空白を含めない (`2i"` 相当)。標準の `a"` が欲しい場面はほぼない
- `dif` や `dii` は中身を消すとインデントだけの行が 1 行残る。書き換えるなら `cif` / `cii` が素直
- `ai` は前後の見出し行 (`def f():` や `end`) まで含む

### 言語ごとによく使う形

| 言語            | 操作                                                                                                   |
| --------------- | ------------------------------------------------------------------------------------------------------ |
| React (JSX/TSX) | `cit` タグの中身、`dat` 要素ごと、`dst` タグを外す、`cst` + タグ名 `<CR>` でタグを変える、`ci"` 属性値 |
| TypeScript      | `ci{` オブジェクトの中身、`ci<` ジェネリクスの中身、`cia` 型付きの引数を丸ごと                         |
| Python          | `]f` `[f` で `def` 間を移動、`cif` 本体、`>ii` / `<ii` でブロックのインデント                          |

JSX ではタグの自動補完も効く (`<div>` と打つと `</div>` が入り、開始タグ名を変えると閉じタグも追従する)。

## Surround

| 操作   | キー                                                            |
| ------ | --------------------------------------------------------------- |
| 囲む   | `ys{motion}{char}`、行全体は `yss{char}`、Visual なら `S{char}` |
| 外す   | `ds{char}`                                                      |
| 変える | `cs{old}{new}`                                                  |

| キー                  | 前                 | 後                   |
| --------------------- | ------------------ | -------------------- |
| `ysiw"`               | `hello`            | `"hello"`            |
| `ysiw)`               | `hello`            | `(hello)`            |
| `ysiw(`               | `hello`            | `( hello )`          |
| `` ysiw` ``           | `hello`            | `` `hello` ``        |
| `yss"`                | `hello world`      | `"hello world"`      |
| `ysiwt` + `div<CR>`   | `hello`            | `<div>hello</div>`   |
| `ysiwf` + `print<CR>` | `value`            | `print(value)`       |
| `ds"`                 | `"hello"`          | `hello`              |
| `dst`                 | `<div>hello</div>` | `hello`              |
| `dsf`                 | `print(value)`     | `value`              |
| `cs"'`                | `"hello"`          | `'hello'`            |
| `cs"t` + `span<CR>`   | `"hello"`          | `<span>hello</span>` |
| `cst"`                | `<div>hello</div>` | `"hello"`            |
| `csf` + `dump<CR>`    | `print(value)`     | `dump(value)`        |

- 開き括弧 `(` `{` `[` `<` で囲むと内側に空白が入り、閉じ括弧 `)` `}` `]` `>` だと入らない
- タグは `t` で入力欄が出る (`ysiw<div>` とは打たない。`<` は `< hello >` になる)
- 略記: `b` = `)`、`B` = `}`、`r` = `]`、`a` = `>`、`q` = 一番近いクォート、`s` = 一番近い囲み (`dsq` `csqb` など)
- Visual の `gS` は囲みを前後の別の行に置く

## コメント

| キー                 | 動作                                                      |
| -------------------- | --------------------------------------------------------- |
| `gcc`                | 行をコメント / 解除                                       |
| `gc{motion}`         | 範囲をコメント (`gcip` 段落、`gcaf` 関数、Visual で `gc`) |
| `gbc` / `gb{motion}` | ブロックコメント (`/* */`)                                |
| `gco` / `gcO`        | 下 / 上にコメント行を作って書き始める                     |
| `gcA`                | 行末にコメントを足して書き始める                          |

JSX / TSX では位置に応じて記法が変わる (JSX の中は `{/* */}`、ロジック部分は `//`)。

## 矩形ビジュアル

`<C-v>` で縦に選び、`I` `A` `c` で入力すると、`<Esc>` を押した時点で全行に反映される。

| やりたいこと                      | キー                                        |
| --------------------------------- | ------------------------------------------- |
| 各行の先頭に挿入                  | `<C-v>` で縦に選ぶ → `I// <Esc>`            |
| 各行の末尾に追加 (長さが違っても) | `<C-v>` で縦に選ぶ → `$` → `A,<Esc>`        |
| 縦の範囲を書き換える              | `<C-v>` で範囲を選ぶ → `c` → 入力 → `<Esc>` |
| 縦の範囲を消す                    | `<C-v>` で範囲を選ぶ → `x`                  |
| 選択の反対の端へ                  | `o`                                         |
| さっきの選択をもう一度            | `gv`                                        |

## Insert モードの小技

| キー              | 動作                                                          |
| ----------------- | ------------------------------------------------------------- |
| `<C-w>`           | 直前の単語を消す                                              |
| `<C-u>`           | 行頭まで消す                                                  |
| `<C-t>` / `<C-d>` | 行のインデントを増やす / 減らす                               |
| `<C-r>{reg}`      | レジスタを貼る (`<C-r>"` 直前のヤンク、`<C-r>0` 最後のヤンク) |
| `<C-r>=`          | 計算した結果を入れる (`<C-r>=60*60*24<CR>` で `86400`)        |
| `<C-v>{key}`      | キーをそのまま入れる (`<C-v><Tab>` でスペースにならないタブ)  |
| `<C-o>{cmd}`      | Normal のコマンドを 1 回だけ (`<C-o>zz` など)                 |
| `<C-g><C-u>` など | カーソル位置の単語の大文字・小文字を変える (この設定)         |

括弧やクォートは閉じる側が自動で入る (nvim-autopairs)。

## ヤンクとレジスタ

- `y` `d` `c` はそのまま macOS のクリップボードに入る。ブラウザでコピーしたものも `p` で貼れる
- 消すだけなら `x` を使うとクリップボードが残る。`d` で消してしまっても、最後に**ヤンク**したものは `"0p` で貼れる
- 貼った直後に `<C-p>` を押すと 1 つ前のヤンク (削除も含む) に差し替わる。`<C-n>` で戻る。もっと前のものは `<leader>y` で選ぶ
- Visual の `p` はレジスタを変えないので、同じ単語で何か所でも置き換えられる (`viwp` → 移動 → `viwp`)
- `]p` は貼る先の行のインデントに揃える。深さの違うブロックへコードを移すときに使う
- `gp` は貼った範囲の直後にカーソルが来るので、続けて貼れる
- ファイル全体をクリップボードに入れるなら `:%y`
- レジスタの中身は `<leader>s"` で一覧できる

### 名前付きレジスタと特殊なレジスタ

クリップボードは `y` や `d` のたびに上書きされる。しばらく使い回したいものは名前付きレジスタに置く。

| レジスタ     | 中身                                    | 例                           |
| ------------ | --------------------------------------- | ---------------------------- |
| `"a` 〜 `"z` | 名前付き。`y` や `d` では上書きされない | `"ayy` で入れて `"ap` で貼る |
| `"A` 〜 `"Z` | 大文字で指定すると追記になる            | `"Ayy` で今の行を `a` に足す |
| `".`         | 最後に Insert モードで入力した文字列    | `".p`                        |
| `":`         | 最後に実行した Ex コマンド              | `@:` でもう一度実行する      |
| `"/`         | 最後の検索パターン                      | コマンドラインで `<C-r>/`    |

レジスタを空にするなら `:let @a = ''` (`qaq` はこの設定では使えない)。

## 行の移動と複製 (:m / :t)

`dd` → `p` で行を動かすとクリップボードが上書きされる。`:m` (move) と `:t` (copy) はレジスタを使わない。

| コマンド           | 動作                                                     |
| ------------------ | -------------------------------------------------------- |
| `:m+1` / `:m-2`    | 今の行を 1 行下 / 上へ                                   |
| `:m0` / `:m$`      | 今の行を先頭 / 末尾へ                                    |
| `:t.`              | 今の行をすぐ下に複製                                     |
| `:-5t.`            | 5 行上の行を、今の行の下に複製 (`:+5t.` なら 5 行下の行) |
| Visual で `:m'>+1` | 選んだ行を 1 行下へ (`:m'<-2` で 1 行上へ)               |
| Visual で `:t'>`   | 選んだ行をすぐ下に複製                                   |

- 行番号は相対表示なので、`:-5t.` の `5` は左に見えている数字をそのまま打てばよい。離れた行を、カーソルを動かさずに手元へ持ってこられる
- 続けて動かすなら `@:` で同じコマンドを繰り返す (2 回目からは `@@`)。Visual で動かした後は `gv` で選び直せる

## ドットリピートと cgn

`.` は直前の「変更」を繰り返す。移動は繰り返さないので、「変更」と「移動」を分けて考える。

| やりたいこと                     | 1 回目        | 2 回目以降             |
| -------------------------------- | ------------- | ---------------------- |
| 行末に `;` を足す                | `A;<Esc>`     | `j.`                   |
| 箇条書きをチェックボックスにする | `^a [ ]<Esc>` | `+.`                   |
| 単語をバッククォートで囲む       | `` ysiw` ``   | `W.`                   |
| 単語を書き換える                 | `ciwfoo<Esc>` | 次の単語へ移動して `.` |

`A` や `I` は行内の位置に関係なく働くので `j.` でよい。`a` は「カーソルの後ろ」に入れるので、`j.` だと列がずれる。`+` (次の行の先頭の非空白文字へ) で位置を揃えてから `.` する。
`` ysiw` `` の直後はカーソルが開いた `` ` `` の上にあるので、`w` だと囲んだばかりの単語に止まって二重に囲んでしまう。`W` で次の WORD へ移る。

行数が多いなら、1 行だけ直してから残りの行を選び、`:normal .` で各行に `.` を流す。

```vim
A;<Esc>        " 1 行目を直す
jVjj           " 残りの行を選ぶ
:normal .      " 選んだ各行で . を実行 (Visual で : を押すと :'<,'> が入る)
```

### cgn

検索の一致そのものを書き換えるなら `cgn` が強い。`gn` は「次の一致を選択」なので、`.` で次の一致へ同じ変更が入る。

```vim
*              " カーソル下の単語で検索を始める (打ち込むなら /old<CR>)
cgnnew<Esc>    " 一致を new に書き換える
.              " 次の一致も書き換える
n              " この一致は飛ばす
.              " その次を書き換える
```

全部まとめてでよければ `:%s` の方が速い。1 つずつ目で確かめたいときに `cgn` を使う。

`.` や `(` などの記号を含む文字列は、Visual で選んで `*` を押すと、エスケープなしでそのまま検索できる。続けて `cgn` でも `:%s//new/g` でも使える。

## マクロ

`.` で届かない「複数ステップ + 位置取り」をまとめて自動化する。

### 基本操作 (この設定)

`q` を誤って押しても記録が始まらないように、`q` 単押しは何もしない。

| キー               | 動作                                                    |
| ------------------ | ------------------------------------------------------- |
| `qq`               | q レジスタに記録開始 (記録中は `● REC @q` の通知が出る) |
| `q`                | 記録停止                                                |
| `Q`                | 再生 (`@q`)。`3Q` で 3 回、`99Q` で止まるまで           |
| 記録中に `Q`       | 停止して、すぐ 1 回再生する                             |
| `@@`               | 直前に再生したマクロをもう一度                          |
| `V` で選んで `Q`   | 選択した行それぞれで再生 (`:'<,'>normal @q` と同じ)     |
| `:g/pat/normal @q` | `pat` に一致する行それぞれで再生                        |

### 組み方のコツ

- **行頭から始める**。最初に `0` か `^` を押して開始位置を固定すると、どこから再生しても同じ結果になる
- **意味のある単位で動く**。`l` の連打ではなく `w` `f{c}` `/pat` を使うと、行ごとに長さが違っても崩れない
- **最後に次の行へ進む** (`j` や `+`)
- **回数は多めに `99Q`**。最終行で `j` が失敗する、検索が当たらない、といったエラーで止まる
- **処理済みの行に当たらない検索にする**。検索はファイル末尾で先頭に戻る (`wrapscan`) ので、`/log` だと `// log` に何度も当たって止まらない。`/^log` のように処理後は当たらない形にする
- **`:g` や Visual の `Q` で流すときは、記録で変わった 1 行を `u` で戻してから** (または、その行を選ぶ範囲から外す)。戻さないとその行だけ二重に入る
- **ヤンクは名前付きレジスタへ** (`"ay`)。無名レジスタはマクロの途中で上書きされやすい

単純な追記なら、マクロを記録せずに `:g/TODO/normal A <-- check` や `:'<,'>normal I// ` と直接書ける。

### 例: 1 行に複数の編集を入れる

接頭辞と接尾辞の 2 か所を直すので、`.` 1 回では再現できない。

```vim
qq          " 記録開始
I"<Esc>     " 行頭に "
A",<Esc>    " 行末に ",
j           " 次の行へ
q           " 停止
99Q         " 残りの行すべてに
```

`apple` → `"apple",`

### 例: 検索を混ぜて飛び飛びの行を処理する

`log` で始まる行だけをコメントアウトする。マクロが自分で次の対象へ飛ぶので、`n` を押す手間がない。

```vim
qq          " 記録開始
/^log<CR>   " 次の log 行へ (行頭に固定したので、処理済みの // log には当たらない)
I// <Esc>   " コメントアウト
q           " 停止
99Q         " 当たらなくなるまで
```

この設定の `/` は very magic なので、`(` `+` `|` などを文字として探すなら `\(` のようにエスケープする。

### 例: 再帰マクロ (回数を数えない)

マクロの最後で自分自身を呼び、エラーで止まるまで走らせる。

```vim
qqq             " q レジスタを空にする (前の記録が残っていると暴走する)
qq              " 記録開始
I"<Esc>A",<Esc> " 1 行分の処理
j               " 次の行へ
@q              " 自分を呼ぶ (今は空なので何も起きない)
q               " 停止
Q               " 1 回呼べば最終行で j が失敗するまで続く
```

### マクロを手直しする

記録し直さず、中身を行として編集して戻す。

```vim
"qp       " q レジスタの中身を貼り出す
          " (貼り出した行を普通に編集する。<Esc> は ^[ の 1 文字で見える)
0"qy$     " 行頭から行末までを q レジスタへ戻す
```

`"qyy` で戻すと末尾の改行まで入り、再生のたびに 1 行余分に下がる。

## 置換 (:s)

`cgn` が「目で見ながら 1 つずつ」なのに対し、`:s` は「条件に合う箇所を一度に」直す。

```vim
:[range]s/pattern/replacement/[flags]
```

| range   | 範囲                                        |
| ------- | ------------------------------------------- |
| (省略)  | 今の行だけ                                  |
| `%`     | ファイル全体                                |
| `'<,'>` | Visual で選んだ行 (選んで `:` を押すと入る) |
| `.,$`   | 今の行から末尾まで                          |
| `.,+5`  | 今の行から 5 行下まで                       |

Visual で選んで `:` を押したときの範囲は行単位なので、選んだ文字の外も置換される。選んだ部分の中だけにするなら pattern に `\%V` を付ける (`:'<,'>s/\%V_/-/g` で、選んだ範囲の `_` だけを `-` に)。

| flag      | 動作                                                             |
| --------- | ---------------------------------------------------------------- |
| `g`       | 行内の一致をすべて置換 (付けないと各行の最初の 1 つだけ)         |
| `c`       | 1 つずつ確認 (`y` 置換 / `n` 飛ばす / `a` 残り全部 / `q` やめる) |
| `n`       | 置換せずに件数を数える                                           |
| `e`       | 一致しなくてもエラーにしない                                     |
| `i` / `I` | 大文字小文字を区別しない / する                                  |

### この設定での注意

`/` キーの very magic はキーマップで付けているだけなので、`:s` には効かない。`:s` で正規表現を素直に書きたいときは先頭に `\v` を付ける。

```vim
:%s/\v(\w+)_(\w+)/\2_\1/g        " \v あり: ( ) + をそのまま書ける
:%s/\(\w\+\)_\(\w\+\)/\2_\1/g    " \v なし: エスケープが要る
```

逆に、記号を文字として探したいなら `\V` を付ける (`:%s/\Vfoo.bar/baz/g`)。
入力中は置換結果がその場でプレビューされる (`inccommand`)。

### replacement の小技

| 記法         | 意味                                  | 例                                        |
| ------------ | ------------------------------------- | ----------------------------------------- |
| `\1` 〜 `\9` | キャプチャした部分                    | `:%s/\v(\w+)_(\w+)/\2_\1/g`               |
| `&`          | 一致した文字列全体                    | `:%s/error/[&]/g` → `[error]`             |
| `\U` / `\L`  | 以降を大文字 / 小文字に (`\E` で解除) | `:%s/\v<(\w)/\U\1/g` (単語の頭を大文字に) |
| `\u` / `\l`  | 次の 1 文字だけ大文字 / 小文字に      |                                           |
| `\r`         | 改行を入れる                          | `:%s/;/;\r/g`                             |
| `\=`         | 式の結果で置換                        | `:%s/\d\+/\=submatch(0)+1/g` (数を +1)    |

一致の範囲は `\zs` (ここから) と `\ze` (ここまで) で狭められる。

```vim
:%s/^\s*\zs- /- [ ] /     " インデントを保ったまま "- " だけをチェックボックスに
```

### よく使う流れ

```vim
:%s/old//gn            " まず件数だけ確かめる
:%s/old/new/g          " 問題なければ実行
:%s/old/new/gc         " 1 つずつ確かめながら
```

```vim
*                      " カーソル下の単語で検索して
:%s//new/g             " pattern を空にすると直前の検索が使われる
```

```vim
:s/old/new/g           " まず今の行だけで試して
g&                     " 良ければ同じ置換を全行に (& なら今の行に繰り返す)
```

```vim
:%s/\s\+$//e           " 行末の空白を消す
```

コマンドラインで `<C-r><C-w>` を押すとカーソル下の単語が入る (`:%s/<C-r><C-w>/new/g`)。

### :g と組み合わせる

`:g/pat/cmd` は `pat` に一致する行だけで `cmd` を実行する。`:v` (= `:g!`) は一致しない行で実行する。

```vim
:g/TODO/s/^/DONE: /        " TODO を含む行の先頭に DONE: を付ける
:g/TODO/normal A <-- check " TODO を含む行の末尾に追記する
:g/^$/d                    " 空行を消す
:v/keep/d                  " keep を含まない行を消す
:g/TODO/m$                 " TODO を含む行を末尾に集める
:g/^/m0                    " 行の順番を逆にする
```

よく使うのは `d` と組み合わせて行を絞る形。説明付きのデフォルト設定 (`ghostty +show-config --default --docs` の出力など) からコメントと空行を消す (`:g/^#/d` → `:g/^$/d`)、貼り付けたログから必要な行だけ残す (`:v/ERROR/d`) といった場面で使う。

一致する行をレジスタに集めて、別のバッファに貼ることもできる。

```vim
:let @a = '' | g/ERROR/y A   " a を空にしてから、ERROR の行を a に追記していく
:new                         " 新しいバッファを開いて
"ap                          " 貼る
```

## 複数ファイルの一括置換

grep の結果を quickfix に送り、その一覧に対して置換を流す。

```text
<leader>/                     置換したい文字列で grep する (<leader>sw ならカーソル下の単語)
<C-q>                         結果を quickfix に送る (<Tab> で選んでいればそれだけ)
:cdo s/old/new/ge | update    一致した行ごとに置換して保存する
```

| コマンド                        | 動作                                                       |
| ------------------------------- | ---------------------------------------------------------- |
| `:cdo {cmd}`                    | quickfix の各行で `{cmd}` を実行 (送った行だけが対象)      |
| `:cfdo {cmd}`                   | quickfix に出てくる各ファイルで 1 回ずつ実行 (`%s` と組む) |
| `:cfdo %s/old/new/ge \| update` | 一致したファイルの中を全部置換して保存                     |
| `:vimgrep /pat/ **/*.ts`        | picker を使わずに quickfix を作る (Vim の正規表現)         |

- 実行前に `<leader>xq` (Trouble) や `]q` / `[q` で対象を確かめられる。要らない行は picker の段階で `<Tab>` で選び分ける
- grep はリテラル (正規表現は picker の中で `<A-r>`)、`:s` は Vim の正規表現。記号を含むなら `s/\Vfoo.bar/baz/ge`
- `c` フラグを付ければファイルをまたいで 1 つずつ確認できる
- 結果は lazygit や hunk で差分を確かめる。まずければ git で戻すのが一番早い

## 並べ替えと外部コマンド

| コマンド              | 動作                                                        |
| --------------------- | ----------------------------------------------------------- |
| `:sort`               | 行を並べ替える (Visual で選んでから `:` なら、選んだ行だけ) |
| `:sort u`             | 並べ替えて、重複した行を消す                                |
| `:sort n` / `:sort i` | 数値の順 / 大文字小文字を区別しない                         |
| `!{motion}`           | 範囲を外部コマンドに通して、出力で置き換える                |
| `!!{cmd}`             | 今の行を外部コマンドに通す (`!!sh` で行をシェルで実行)      |
| `:%!{cmd}`            | ファイル全体を外部コマンドに通す                            |
| `:r !{cmd}`           | コマンドの出力をカーソルの下に入れる                        |

`!ip` と打つとコマンドラインに `:.,.+3!` のような範囲が入るので、続けてコマンドを打つ。結果がまずければ `u` で戻せる。

```text
vi[ → :sort u                  Nix の [ ... ] の中を並べ替えて重複を消す
:%!jq .                        1 行に詰まった JSON を読める形にする
:%!sort | uniq -c | sort -rn   同じ行を数えて多い順に並べる (ログの集計)
:r !git log --oneline -5       最近のコミットを貼る
```

## 増減と切り替え

`<C-a>` / `<C-x>` は dial.nvim で拡張していて、カーソル位置 (なければ行内でその先) の値を判定して増減・切り替えする。

| 対象    | 例                  | `<C-a>` の後                           |
| ------- | ------------------- | -------------------------------------- |
| 10 進数 | `42`                | `43`                                   |
| 16 進数 | `0xff`              | `0x100`                                |
| semver  | `v1.2.9` (`9` の上) | `v1.2.10`                              |
| 日付    | `2024-01-31`        | カーソルのある桁 (年 / 月 / 日) を増減 |
| 時刻    | `09:59`             | カーソルのある桁 (時 / 分) を増減      |
| 真偽値  | `true` / `True`     | `false` / `False`                      |
| 演算子  | `&&` / `==` / `and` | `\|\|` / `!=` / `or`                   |

- `-` は符号として扱わない。`-1` で `<C-a>` を押すと `-2` になる
- Visual で `<C-a>` は選択内の数値をまとめて +1、`g<C-a>` は行ごとに +1, +2, +3 … (連番)

連番は「同じ行を並べて `g<C-a>`」が最短。

```vim
yy4p      " 行を 5 行にする
ggVG      " 全部選ぶ
g<C-a>    " test_case_0 × 5 → test_case_1 〜 test_case_5
```

## コマンドラインの小技

| キー                | 動作                                                                    |
| ------------------- | ----------------------------------------------------------------------- |
| `@:`                | 直前の Ex コマンドをもう一度 (2 回目からは `@@`)                        |
| `<Up>` / `<Down>`   | 打ちかけの文字で始まる履歴だけを辿る (`:%s` まで打って `<Up>`)          |
| `<C-f>`             | 打っている途中のコマンドを、Normal モードのキーで直せる窓に移す         |
| `<C-r><C-w>`        | カーソル下の単語を入れる                                                |
| `<C-r><C-a>`        | カーソル下の WORD を入れる (`docs/nvim/README.md` のようなパスを丸ごと) |
| `<C-r>/` / `<C-r>"` | 直前の検索パターン / 直前のヤンクを入れる                               |
| `<leader>:`         | コマンド履歴から選ぶ                                                    |
| `:={式}`            | Lua の式を計算して表示する (`:=60*60*24`、`:=vim.bo.filetype`)          |

- `<C-f>` で開く窓には履歴が普通の行として並ぶ。`k` で上の履歴へ移って直し、`<CR>` で実行する。閉じるなら `:q`。`/` の入力中でも使える
- 素の Vim の `q:` (この窓を開く) と `q/` は使えない (`q` を prefix にしているため)

## undo をさかのぼる

| コマンド                      | 動作                                                |
| ----------------------------- | --------------------------------------------------- |
| `:earlier 1f` / `:later 1f`   | 最後に保存した時点へ戻る / 進む (`f` は保存 1 回分) |
| `:earlier 10m` / `:later 10m` | 10 分前の状態へ戻る / 進む (単位は `s` `m` `h` `d`) |
| `:e!`                         | 最後に保存してからの変更を捨てる (`u` で取り消せる) |
| `<leader>su`                  | undo の履歴を一覧から選んで戻る                     |

- 外で書き換えられて自動で読み直したファイルも、`u` で読み直す前の内容に戻せる (10000 行未満のファイルに限る)。Claude Code の変更をまるごと取り消したいときに使える。戻した内容は、保存するまでディスクには反映されない
- nvim を閉じると undo の履歴は消える (`undofile` は使っていない)

## 差分を見比べる

| キー / コマンド   | 動作                                                           |
| ----------------- | -------------------------------------------------------------- |
| `:windo diffthis` | 今のタブに並べた 2 つのウィンドウを比べる (`:diffoff!` で解除) |
| `nvim -d a b`     | シェルから 2 つのファイルを比べて開く                          |
| `]h` / `[h`       | 次 / 前の変更箇所 (git 管理下のファイルを開いた側でだけ効く)   |
| `dp`              | カーソル位置の差分を、相手側へ送る (diff put)                  |
| `do`              | 相手側の内容を、こちらへ取り込む (diff obtain)                 |
| `:diffupdate`     | 差分の表示がずれたら計算し直す                                 |

`]c` はこの設定ではクラスの移動なので、diff の移動には `]h` を使う。

### Claude Code の提案を一部だけ断る

提案の diff (左が元のファイル、右が提案) で、断りたい変更だけを元に戻してから採用する。

```text
<C-h>          左 (元のファイル) へ移る
]h             断りたい変更へ移る (右の提案側は git の管理外なので ]h が効かない)
dp             元の内容を右へ送る (= その変更だけ断る)
<C-l>          右 (提案) へ戻る
<leader>aa     残りを採用する (:w でも同じ)
```

`<leader>aa` と `:w` は右 (提案) で押す。左で押しても採用にならない。

## 日本語と文字コード

| コマンド                 | 動作                                                                    |
| ------------------------ | ----------------------------------------------------------------------- |
| `gJ`                     | 行をつなぐ。`J` と違って間に空白を入れない (日本語の行をつなぐとき)     |
| `g<C-g>`                 | 文字数・単語数を数える (Visual なら選んだ範囲)                          |
| `ga`                     | カーソル下の文字のコードを見る (全角スペースなら `U+3000`)              |
| `/%u3000`                | 全角スペースを探す (この設定の `/` は very magic なので `\` を付けない) |
| `:%s/\%u3000/ /g`        | 全角スペースを半角にする (`:s` には `\` が要る)                         |
| `:e ++enc=cp932`         | Shift_JIS として開き直す                                                |
| `:set fenc=utf-8` → `:w` | UTF-8 に変換して保存                                                    |
| `:set ff=unix` → `:w`    | 改行コードを CRLF から LF にして保存                                    |
| `:set bomb` → `:w`       | BOM を付けて保存 (Excel に UTF-8 の CSV を文字化けせずに開かせる)       |
| `:set fenc? ff? bomb?`   | 今の文字コード・改行コード・BOM の有無を見る                            |

- Shift_JIS のファイル (Excel から書き出した CSV など) は文字化けして開く。Neovim の既定では、文字コードを判定する候補に Shift_JIS が入っていないため。`:e ++enc=cp932` で開き直す
- CRLF のファイルは自動で判定され、改行コードを保ったまま保存される。行末に `^M` が見えるのは CRLF と LF が混ざっているときで、`:%s/\r$//` で消せる
- `g<C-g>` の文字数は行末の改行も 1 文字に数える。日本語の文は空白で区切られないので、単語数は当てにならない

## ヘルプを引く

キーやコマンドの意味は `:h` で引ける (`<leader>sh` なら一覧から探せる)。モードごとに付ける接頭辞が決まっている。

| 引きたいもの         | 書き方   | 例                   |
| -------------------- | -------- | -------------------- |
| Normal のキー        | そのまま | `:h gJ`、`:h CTRL-O` |
| Visual のキー        | `v_`     | `:h v_o`             |
| Insert のキー        | `i_`     | `:h i_CTRL-R`        |
| コマンドラインのキー | `c_`     | `:h c_CTRL-F`        |
| Ex コマンド          | `:`      | `:h :sort`、`:h :g`  |
| オプション           | `'名前'` | `:h 'wrap'`          |
| 正規表現             | `/`      | `:h /\zs`、`:h /\%V` |

- ヘルプの中では `<C-]>` でリンク先へ飛び、`<C-o>` で戻る。`gO` で目次を出す
- 体系立てて覚えるなら、ユーザーマニュアル `:h usr_toc` (日本語) を 1 章ずつ読む。Vim のマニュアルの訳なので、Neovim と食い違ったら `:h {tag}@en` を見る
- 手を動かして覚えるなら `:Tutor ja/vim-01-beginner` (日本語のチュートリアル。続きは `ja/vim-02-beginner`)
