# Neovim 普段使い

この設定で毎日使う操作を「やりたいこと → キー」でまとめた入口ページ。
Leader は `<Space>`。キーを忘れたら `<Space>` を押して待つ (which-key) か、`<leader>sk` でキーマップを検索する。

## 素の Vim と違うところ

知らないと事故りやすい順。

| キー / 挙動       | この設定での動き                                                                                                |
| ----------------- | --------------------------------------------------------------------------------------------------------------- |
| `y` `d` `c`       | macOS のクリップボードに入る (`clipboard=unnamedplus`)。`dd` でもクリップボードが上書きされる                   |
| `x`               | レジスタを汚さない**削除オペレータ**。`xx` で行、`xiw` で単語、`X` で行末まで。1 文字だけなら `xl`              |
| Visual `p`        | 貼っても元のレジスタが残る (同じものを何度でも貼れる)                                                           |
| `u` / `U`         | undo / **redo**                                                                                                 |
| `q`               | 単押しでは記録しない。`qq` で記録、`q` で停止、`Q` で再生。`qo` は他のウィンドウを閉じる、`qt` は直前のバッファ |
| `M`               | 対応する括弧や `if` / `else` / `end` へジャンプ (本来の「画面中央の行へ」ではない)                              |
| `/` / `?`         | `/` は very magic (`(` `+` `\|` をそのまま正規表現に使える)。`?` は記号をそのまま探す後方検索                   |
| `<leader>/`       | プロジェクト grep は**リテラル**。正規表現にしたいときは picker の中で `<A-r>`                                  |
| `gr`              | LSP の参照一覧。Neovim 標準の `grn` `gra` などは使えないので `<leader>rn` `<leader>ca` を使う                   |
| `]c` / `[c`       | クラス単位の移動。diff の変更箇所へ移動するのは `]h` / `[h`                                                     |
| `;` / `,`         | `f` `t` だけでなく `]h` `]f` などの移動も繰り返す。`;` は直前と同じ向き、`,` は逆向き                           |
| `<C-a>` / `<C-x>` | 数値だけでなく `true`/`false`、日付、semver、`&&`/`\|\|` も切り替える                                           |
| `jk`              | `<Esc>` (Insert / Visual / コマンドライン / ターミナル)                                                         |
| `<C-h/j/k/l>`     | ウィンドウ移動。端まで来たら herdr のペインへ抜ける                                                             |
| 空行で `i` / `A`  | インデント位置から書き始める                                                                                    |

## 勝手に起きること

- **外で変更されたファイルは自動で読み直す**。Claude Code が書き換えたファイルも、フォーカス・バッファ移動・少し手を止めたタイミングで反映される (`Reloaded from disk` と通知)。こちらに未保存の変更があると警告が出るので、任せている間はこまめに `:w`
- **20 分触っていないバッファは自動で閉じる** (バッファが 4 つ以上あり、画面に出ておらず、未保存の変更がないもの)。`<leader>,` から消えていても `<leader><space>` の履歴から開ける
- **保存時の自動整形はしない**。整形は `<leader>fm`
- ステータスラインとコマンドラインは出さない。ファイル名と診断数は右下、`:` は画面上部のポップアップ、`/` 検索は画面下部に出る。マクロ記録中は `● REC @q` の通知が出る
- スワップファイルは作らない。長い行は折り返さない (文章を書くときは `:set wrap`)

## 作業別の最短手順

### ファイルを開く・探す

| やりたいこと                                                    | キー                                          |
| --------------------------------------------------------------- | --------------------------------------------- |
| ファイルを開く (開いているもの・最近・全ファイルからよく使う順) | `<leader><space>`                             |
| 開いているバッファから選ぶ                                      | `<leader>,`                                   |
| 直前のバッファと行き来する                                      | `qt`                                          |
| プロジェクト全体を grep                                         | `<leader>/`                                   |
| カーソル下の単語 / 選択範囲で grep                              | `<leader>sw`                                  |
| 今のファイルの中を絞り込む                                      | `<leader>sb`                                  |
| gitignore されたものも含めて探す                                | `<leader>fa` (ファイル) / `<leader>sG` (grep) |
| ディレクトリ構成を見る                                          | `<leader>e` (`q` で閉じる)                    |
| さっきの picker を開き直す                                      | `<leader>sR`                                  |
| 別のプロジェクトへ移る                                          | `<leader>fp`                                  |

picker の中でよく使うキー (全部は [keymaps.md の Picker](keymaps.md#picker)):

| キー                        | 動作                                                 |
| --------------------------- | ---------------------------------------------------- |
| `<C-j>` / `<C-k>`           | 候補を上下                                           |
| `<CR>` / `<C-v>` / `<C-s>`  | 開く / 縦分割で開く / 横分割で開く                   |
| `<Tab>`                     | 複数選択                                             |
| `<C-q>`                     | quickfix に送る (選んでいればそれだけ、なければ全部) |
| `<A-h>` / `<A-i>` / `<A-r>` | hidden / ignored / 正規表現 を切り替え               |
| `<Esc>` を 2 回             | 閉じる (1 回目は入力欄のノーマルモードに入るだけ)    |

### コードを読む

| やりたいこと                             | キー                                                             |
| ---------------------------------------- | ---------------------------------------------------------------- |
| 定義へ飛ぶ / 戻る / また進む             | `gd` / `<C-o>` / `<C-i>`                                         |
| 参照一覧                                 | `gr`                                                             |
| 実装 / 型定義へ                          | `gI` / `gy`                                                      |
| ドキュメントを見る                       | `K`                                                              |
| 定義をその場でのぞく (ジャンプしない)    | `<leader>pd` (のぞいた先で `<CR>` で開く、`<leader>pc` で閉じる) |
| シンボル一覧 (ファイル / ワークスペース) | `<leader>ss` / `<leader>sS`                                      |
| 次 / 前の関数、クラス                    | `]f` / `[f`、`]c` / `[c`                                         |
| インデントブロックの上端 / 下端へ        | `[i` / `]i`                                                      |
| 対応する括弧・`if` … `end` へ            | `M`                                                              |
| 型ヒントを行内に表示                     | `<leader>uh`                                                     |

画面上端には今いる関数・クラスの行が固定表示される (treesitter-context、`<leader>ut` で切り替え)。

### 書く

| やりたいこと                               | キー                                                |
| ------------------------------------------ | --------------------------------------------------- |
| 補完を選ぶ / 確定 / 閉じる                 | `<C-j>` `<C-k>` / `<CR>` / `<C-e>`                  |
| スニペットの次 / 前の入力欄へ              | `<Tab>` / `<S-Tab>`                                 |
| 行をコメント / 範囲をコメント              | `gcc` / `gc{motion}` (`gcip` で段落、`gcaf` で関数) |
| 下 / 上 / 行末にコメントを書き足す         | `gco` / `gcO` / `gcA`                               |
| 囲む / 外す / 変える                       | `ysiw"` / `ds"` / `cs"'` (Visual なら `S"`)         |
| 関数呼び出しで囲む / 外す                  | `ysiwf` + 関数名 `<CR>` / `dsf`                     |
| 選択を構文単位で広げる / 狭める            | Visual で `an` / `in`                               |
| 貼った直後に、もっと前のヤンクへ差し替える | `<C-p>` (戻すのは `<C-n>`)                          |
| ヤンク履歴から選んで貼る                   | `<leader>y`                                         |
| 今の行のインデントに揃えて貼る             | `]p` (上に貼るなら `[p`)                            |
| 下 / 上に空行を足す                        | `]<Space>` / `[<Space>`                             |
| 数値や `true` / `false` を増減・切り替え   | `<C-a>` / `<C-x>`                                   |

### Git

| やりたいこと                 | キー                                                                          |
| ---------------------------- | ----------------------------------------------------------------------------- |
| 変更箇所 (hunk) へ移動       | `]h` / `[h` (続けて移動するなら `;` / `,`)                                    |
| hunk の差分を見る            | `<leader>ghp`                                                                 |
| hunk をステージ / 元に戻す   | `<leader>ghs` / `<leader>ghr`                                                 |
| この行を誰がいつ書いたか     | `<leader>ghb`                                                                 |
| ステージング・コミット・push | `<leader>lg` (lazygit。操作は [lazygit.md](../git/lazygit.md))                |
| このファイルの履歴           | `<leader>lf` (lazygit) / `<leader>gf` (picker)                                |
| この行の履歴                 | `<leader>gL`                                                                  |
| GitHub で開く                | `<leader>gB`                                                                  |
| 変更全体をレビューする       | nvim の外の hunk (herdr の `Prefix + Shift + H`。[操作](../hunk/COMMANDS.md)) |

### 複数ファイルを一括置換

1. `<leader>/` で対象を grep する (カーソル下の単語なら `<leader>sw`)
2. picker の中で `<C-q>` を押して結果を quickfix に送る
3. `:cdo s/old/new/ge | update` で、一致した行ごとに置換して保存する

送った一覧は `<leader>xq` (Trouble) で見たり `]q` / `[q` で順に辿ったりできる。
grep はリテラル検索だが `:s` は Vim の正規表現なので、`.` や `[` を含むなら `s/\Vfoo.bar/baz/ge` のように `\V` を付ける。
詳しくは [editing.md の一括置換](editing.md#複数ファイルの一括置換)。

### ウィンドウ

| やりたいこと              | キー                                                      |
| ------------------------- | --------------------------------------------------------- |
| 縦 / 横に分割             | `<leader>wv` / `<leader>wh`                               |
| 移動                      | `<C-h>` `<C-j>` `<C-k>` `<C-l>` (端なら herdr のペインへ) |
| 閉じる / これ以外を閉じる | `<leader>wx` / `qo`                                       |

| 集中モード                | `<leader>z`                                               |

### Claude Code と並べて使う

- `<leader>cp` で今のファイルの相対パスをコピーし、Claude Code のプロンプトに `@` を付けて貼る
- Claude Code の編集は自動で読み直されるので、`]h` と `<leader>ghp` でそのまま差分を確かめられる
- まとまった変更は hunk を横のペインに開いておく (`--watch` で編集に追従する)

### 困ったとき

| 状況                     | 手段                                                                     |
| ------------------------ | ------------------------------------------------------------------------ |
| キーを忘れた             | `<Space>` を押して待つ / `<leader>sk`                                    |
| キーがどこで定義されたか | `:verbose nmap <キー>`                                                   |
| 通知・メッセージを見返す | `<leader>snh`                                                            |
| LSP の様子がおかしい     | `:lsp restart`。状態は `:checkhealth vim.lsp`、サーバーの導入は `:Mason` |
| 整形されない             | `:ConformInfo`                                                           |
| プラグインの状態・更新   | `:Lazy`                                                                  |
| ヘルプを引く             | `<leader>sh`                                                             |
